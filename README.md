# Mothers Who Grow — Static Site

This is a ready-to-go static website for GitHub Pages.

## Deploy on GitHub Pages

1. Create a new repository on GitHub (public is fine).
2. Upload (or drag & drop) the contents of this folder into the repository root.
3. Commit and push.
4. In the repository, go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the **main** branch and `/ (root)`.
7. Click **Save**. Your site will be available at the URL GitHub shows.

> Tip: If your site doesn’t show, make sure a file named `index.html` is in the repository root and try adding a `.nojekyll` file to disable Jekyll processing.
